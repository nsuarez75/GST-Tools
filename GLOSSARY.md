# Glosario

Vocabulario común a las aplicaciones. El de cada una está en el `GLOSSARY.md` de su repositorio.

- **SICAR@GST**: estándar de programación de PLC de GESTAMP para las líneas de producción.
- **LoS** (List of Signals): Excel con las señales I4.0 que intercambian los PLC con el IPC.
- **FIT**: Excel con todas las features de una pieza para la plataforma I4 de GESTAMP.
- **Openness**: interfaz de TIA Portal para que otras aplicaciones lean y escriban un proyecto. Exige .NET Framework 4.8.
- **Fuente externa**: archivo de texto (`.db`, `.awl`, `.udt`, `.scl`) que TIA Portal convierte en bloques.
